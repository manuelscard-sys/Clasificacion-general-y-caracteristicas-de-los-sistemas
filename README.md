# Clasificación general y características de los sistemas – OVA de Teoría General de Sistemas

## Descripción

Objeto Virtual de Aprendizaje (OVA) desarrollado para la asignatura Teoría General de Sistemas, de Ingeniería de Sistemas en la Universidad Simón Bolívar, Sede Cúcuta. Explica de forma breve y sencilla las principales clasificaciones de los sistemas y sus características, mediante ejemplos, videos, ejercicios con retroalimentación, juegos interactivos y un quiz de repaso con puntaje automático.
